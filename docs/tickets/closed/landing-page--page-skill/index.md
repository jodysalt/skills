# Implementation notes
- Draft through `jodysalt:add-skill`'s template by hand rather than running the skill, since the slice already holds every answer; keep its paragraph-title-argument-steps-rules shape and its description in three parts.
- Step 2's framing copies `skills/add-ticket/SKILL.md` step 7's shape: subject, what is settled, what is explorable (the repo, `docs/glossary.md`), what is edited as answers land – here nothing until the interview closes, since one page is written from every answer; a deferred answer becomes a `TODO:` in the written file, not a question later. - `og:url` needs the GitHub user and repo: parse `git remote get-url origin` for `github.com[:/]{user}/{repo}(.git)?`; no match, no tag.
- The README row's text is the description's first sentence; the table's first data row is `add-skill`, so the new row goes above it.
